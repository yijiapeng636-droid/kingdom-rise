# 测试与验收

## 自动测试

`npm test`：纯 Node 原生测试，不依赖 Vue/Phaser/browser 环境；覆盖起始状态、格坐标往返、建造资源扣除与冲突、居民施工与农田、升级/HP、固定 dt/暂停、同帧攻击、攻击与俘虏、重复领取、A*、第 3 天袭击、资源容量、保存/读取/新游戏及损坏存档回退。

`npm run typecheck:domain`：用 `tsc` 静态检查纯 TS 规则及 Controller（不需要安装 Phaser/Vue）。

`npm run build`：依赖安装后用 `vue-tsc` 检查整个 Vue + Phaser 项目并构建生产包。**交付环境无法连接 npm 软件源，因此这一步尚未验证。**

## 手动验收路径

1. `npm install && npm run dev`，检查场景与左右侧栏出现，开局木 20 / 石 10 / 粮 30、5 名居民。
2. 左键领袖，再右键树、石矿和野果，观察领袖移动以及三类资源增长；滚轮缩放和 F 跟随。
3. 切换「营地建造」建住房、农田、仓库；格子预览绿/红色，重复放置被拒，库存即时扣除；指派一位「施工」居民，确认三阶段外观和完工。
4. 指派「务农」居民，完成农田后产出食物；木工、采石工进入岗位后产出，经验和等级增长。
5. 观察进入第 2 日后粮食定时扣除、忠诚度变化。暂停期间地图角色/规则停止，恢复及 2× 改变推进速度。
6. 等第 3 日或点「提前触发袭击」。确认三名强盗出现，选中居民右键攻击，在战斗中其他未接敌居民仍能工作。胜利后查看战利品、俘虏和伤员。
7. 连续点击「领取战利品」，确认不能重复。释放一个俘虏，确认人物 ID 不变、人数不被复制。
8. 手动保存、刷新，确认建筑状态、坐标、等级经验和袭击记录都恢复；点「新游戏」确认彻底重置。
